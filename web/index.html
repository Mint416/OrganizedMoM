About this demonstration

The app replays the August 13, 2026 BYGA/LingoAce example from your Module 3 plan. It uses six Python specialist roles, TF-IDF and latent semantic retrieval, deterministic scheduling checks, bounded beam search, and SQLite memory.

It runs locally on your Mac. No website passwords are collected. Real Gmail and calendar access uses a separate read-only OAuth setup. External calendar updates and email replies are disabled.

See the GitHub-ready project plan and integration guide in the project folder for the next stages.
